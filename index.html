About Minesweeper

Minesweeper

A faithful recreation of the 1992 Windows 3.1 classic, built with vanilla HTML, CSS and JavaScript. No frameworks, no external assets, no network dependencies.

Clear the minefield without detonating a mine. The numbers tell you how many mines touch each square.

How to Play

Goal: reveal every square that does not hide a mine.

  • Left-click a covered square to reveal it. The first reveal is always safe.
  • A revealed number counts the mines in the 8 surrounding squares.
  • Right-click a covered square to cycle: flag → question mark → covered. Flags mark suspected mines; turn off "Marks (?)" in the Game menu to skip the question mark.
  • Chord: left-click a revealed number whose flag count already matches it to reveal its remaining neighbors at once.
  • The smiley starts a new game in any situation.
  • Difficulties: Beginner 9×9 with 10 mines, Intermediate 16×16 with 40 mines, Expert 30×16 with 99 mines, plus Custom.
