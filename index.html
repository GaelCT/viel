About Minesweeper

Minesweeper

A faithful recreation of the 1992 Windows 3.1 classic, built with vanilla HTML, CSS and JavaScript. No frameworks, no external assets, no network dependencies.

Clear the minefield without detonating a mine. The numbers tell you how many mines touch each square.

How to Play

Goal: reveal every square that does not hide a mine.

  • Left-click a covered square to reveal it. The first reveal is always safe.
  • A revealed number counts the mines in the 8 surrounding squares.
  • Right-click a covered square to cycle: flag → question mark → covered. Flags mark suspected mines; turn off "Marks (?)" in the Game menu to skip the question mark.
  • Chord: left-click a revealed number whose flag count already matches it to reveal its remaining neighbors at once.
  • The smiley / New restarts the current game. In a challenge it keeps the identical board. Difficulty / Custom starts a classic random game.
  • Daily Challenge: choose a difficulty in Game. Each UTC date has a fixed board with an automatic safe center opening. Boards are not guaranteed guess-free.
  • Share / Import Challenge: copy a code (manual copy works offline), then import it to play the same board. Codes contain no moves or player data.
  • Resume: challenge moves, marks and active seconds save locally when storage is available. Reload resumes; hidden or closed time is paused. Classic records stay separate.
  • Replay: after finishing, use play, pause, step or restart. Exit restores your live game. Board and New/difficulty controls are disabled during replay.
  • Challenge History: replay or clear local results. Only the newest 30 attempts within 2 MiB are kept. Each attempt allows 4096 actions and one year of active seconds. No data leaves this browser.
  • Difficulties: Beginner 9×9 with 10 mines, Intermediate 16×16 with 40 mines, Expert 30×16 with 99 mines, plus Custom.
